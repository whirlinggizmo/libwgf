Every program is a release web build, as a page ships it; sizes in KB. Why each number is what it is, and how it was found, is HISTORY.md's ("Web sizes, measured" and after).

Measured from libwgf 8b63664 2026-10-06, libwgt 8871e04 2026-10-05, wgrender-c 25ef6fd 2026-10-05, with Emscripten 5.0.7.
