# Asteroids

libwgf's first game: a ship, rocks that split, bullets, wraparound, score, lives, sounds, particles, and a title and a game-over screen built with libwgf's UI. Play it at [whirlinggizmo.github.io/libwgf/asteroids](https://whirlinggizmo.github.io/libwgf/asteroids/).

Turn with Left and Right (or A and D, a pad's D-pad or left stick), thrust with Up (W, the pad's south button or right trigger), fire with Space (the pad's east button or right bumper). A ship every 10,000 points.

```sh
wgf serve                                  # in a browser, reloading as you save
wgf autopilot autopilot/playthrough.autopilot  # the playthrough, headless (--web: in a browser)
wgf export                                 # export/web (held to wgf.json's budget) and export/desktop
python3 tools/gen_sounds.py                # its sounds, generated (from libwgf's root)
```

- `src/`: `Main` (the states, waves, score, the screens), `Ship`, `Rock`, `Bullet` (each a behavior, wgf.Behavior), `Sounds`.
- `assets/scenes/asteroids.scene`: the prefabs -- the ship, three rocks, the bullet, the explosion -- with their components. The ecs moves, wraps, ages, and overlaps them; the scripts set intent.
- `assets/sounds/`: generated by `tools/gen_sounds.py` and committed.
- `autopilot/playthrough.autopilot`: the title, a game played to its game over, and a second game started; `autopilot/smoke.autopilot`: what an export's smoke run plays.
